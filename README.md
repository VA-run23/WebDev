# 📚 Delta 2.0

This repository contains the **codes and programs** I developed during my **Delta 2.0 Course** (a **self‑paced online program** offered by *Apna College*) from **August  2023 to May 2024**.  

Since it was self‑paced, I took additional time to balance the coursework alongside my academic responsibilities. This repository reflects my complete learning journey across web development concepts, problem‑solving, and project building.  

---

## ⏳ Why the Delay in Uploading?  

I took **longer than expected** to upload this repository for two main reasons:  

1. **Balancing Academics & Learning**  
   Managing my academic workload alongside the Delta 2.0 program was challenging, so I needed extra time to complete everything properly.  

2. **Sensitive Information in Files**  
   Some of my project files contained **personal information** (like passwords, emails, and phone numbers). Before uploading, I had to carefully scan and clean them.  

   To solve this, I built a custom **JavaScript script (`detect.js`)** that automatically scans files for sensitive data. You can find this script in the **root of this repository**. This idea came to me recently, and once I implemented it, I was finally confident to upload my work safely.
